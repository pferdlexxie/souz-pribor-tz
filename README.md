# Генератор черновиков карточек товаров

## Установка и запуск

Убедитесь, что на устройстве установлен Python 3.9+

1. Скачайте репозиторий и перейдите в его папку.
2. Создайте файл `.env` и впишите значения из электронного письма:

   ```
   YANDEX_API_KEY=ваш_ключ
   YANDEX_FOLDER_ID=идентификатор_каталога
   YANDEX_MODEL=выбранная модель
   ```

3. Запустите:

   ```
   python generate.py examples/products.json
   ```

Результаты появятся в папке `results/`: по одному файлу `product_01.json`, `product_02.json`.
